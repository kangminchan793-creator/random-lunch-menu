# 🍽️ 랜덤 점심 메뉴 추천 웹 프로그램

오늘 점심 메뉴를 고민할 때 버튼 한 번으로 메뉴를 추천받고, 새 메뉴를 추가하거나 삭제하며 카테고리별로 골라볼 수 있는 웹 프로그램입니다.

## 주요 기능
- **랜덤 메뉴 추천:** 등록된 메뉴 중 하나를 무작위로 추천해 줍니다.
- **카테고리 필터링:** 전체, 한식, 중식, 일식, 양식/기타 카테고리로 나누어 메뉴를 보고 추천받을 수 있습니다.
- **메뉴 추가 및 삭제:** 새 메뉴를 중복 검사 후 추가할 수 있고, `×` 버튼으로 메뉴를 삭제할 수 있습니다.

## 사용 방법
1. 상단 카테고리 버튼으로 원하는 음식 종류를 선택합니다(기본값: 전체).
2. **랜덤 메뉴 추천받기** 버튼을 눌러 오늘의 메뉴를 확인합니다.
3. 메뉴를 추가하려면 카테고리와 메뉴 이름을 입력하고 **추가** 버튼을 누르거나 enter 키를 누릅니다.
4. 메뉴 태그의 `×` 버튼을 누르면 해당 메뉴가 삭제됩니다.
